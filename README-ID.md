# AvatarChanger By ForktHubX ( Executor )

**Script pengelola avatar Roblox dengan preview 3D dan fitur try-on lokal.**

## Fitur

- Simpan avatar sendiri atau pemain lain.
- Cari avatar menggunakan username Roblox.
- Kelola daftar avatar.
- Preview avatar dalam tampilan 3D.
- Coba avatar secara lokal.
- Dukungan rig R6 dan R15.
- Tampilan UI untuk desktop dan mobile.

## Cara Menjalankan

Salin kode berikut, lalu jalankan melalui executor yang mendukung `loadstring` dan `game:HttpGet`.

```lua
loadstring(game:HttpGet("https://script.forkthubx.workers.dev/raw/vGkhYqoEwM"))()
```
